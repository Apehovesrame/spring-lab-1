## Цель работы
Реализация веб-приложения (Лабораторная работа №1) на базе Spring Boot для сбора, обработки и вывода информации о студентах с автоматической генерацией номера учебной группы и логина.

## Архитектура проекта
- **Стек:** Spring Boot 3, Java, Thymeleaf, Maven/Gradle
- **Основные слои:**
  - **Model (Модель):** Класс `Student.java`[cite: 3] — отвечает за структуру данных сущности и содержит бизнес-логику инкапсулированную в методе `generateGroupAndLogin()`.
  - **Controller (Контроллер):** Класс `MainController.java`[cite: 2] — обрабатывает входящие HTTP-запросы (GET и POST), инициализирует модели и маршрутизирует пользователя по страницам.
  - **View (Представления):** HTML-страницы (`main.html`, `about.html`, `main-form.html`, `result.html`)[cite: 4, 5, 6, 7], использующие шаблонизатор Thymeleaf для динамического отображения данных.
  - **Configuration (Конфигурация):** Файл `application.properties`[cite: 8], задающий имя приложения и кастомный порт сервера (8083).
- **Ключевые аннотации:**
  - `@SpringBootApplication` — конфигурация и точка входа в приложение.
  - `@Controller` — указывает, что класс является веб-контроллером Spring MVC.
  - `@GetMapping` / `@PostMapping` — маппинг методов на обработку GET и POST запросов по определенным URL-адресам.
  - `@RequestParam` — извлечение параметров (например, имени) из строки запроса URL.
  - `@ModelAttribute` — связывание данных отправленной HTML-формы с объектом Java (в данном случае, `Student`).

## Алгоритм работы
1. Приложение запускается на локальном сервере, используя порт `8083`.
2. При переходе на корневой адрес (`/`) пользователю отображается главная страница с навигацией: ссылками на страницу автора и форму ввода данных.
3. При переходе по ссылке на `/form` (GET-запрос) контроллер передает в представление `main-form.html` пустой объект `Student`.
4. Пользователь заполняет поля формы (ID, ФИО, email, год поступления) и отправляет данные.
5. Контроллер перехватывает POST-запрос на `/form` и автоматически маппит введенные значения в поля объекта `Student`.
6. Вызывается бизнес-логика `student.generateGroupAndLogin()`: на основе года поступления формируется строка группы (вида `ПИНз-1ХХ`), а затем генерируется логин с использованием сформированной группы и ID.
7. Итоговый объект передается в модель, и пользователю возвращается отрендеренная страница `result.html` с карточкой студента.
